# Scrollable Waypoints

A [D2RLoader](https://github.com/D2RLoader) plugin for Diablo II: Resurrected that lets you scroll through the
waypoint Act tabs with your mouse wheel. Scroll down for the next Act, up for the previous one.

## Requirements

- Diablo II: Resurrected 3.3
- D2RLoader 1.3.1

Works with or without mods. On any other game or D2RLoader version the plugin switches itself off.

## Install

1. Close the game.
2. Download `scrollable-waypoints.dll` from the [latest release](https://github.com/synpoox/scrollable-waypoints/releases/latest).
3. Copy it into `<game folder>\d2rloader\plugins\`. Create the `plugins` folder if it doesn't exist.
4. Start the game through D2RLoader.

To uninstall, delete the DLL.
